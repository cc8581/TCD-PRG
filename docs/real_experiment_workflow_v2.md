# 真实实验平台运行流程 V2

状态：2026-09-18 用户确认；取代 `real_experiment_design_requirements.md` 中关于自动流程、PICK_REMOVE 与 PyBullet 筛选的旧运行路径。训练数据、检查点与 Stage-C 监督协议不因此修改。

## 模式与共同决策

- UI 顶部滑动开关切换“仿真”和“真机”，下方两套独立功能按钮区只显示当前模式的一套。仿真不连接或驱动机械臂，末端仅展示候选动作与分支结果。切换模式会清空当前场景和决策状态；设备已连接或任务运行时不可切换。
- 仿真：加载 G 盘选定场景对应的 F 盘现有缓存 → 手动实例分割 → 手动确认目标/类别/功能区 → 手动启动目标抓取预测。
- 真机：点云采集 → 手动实例分割 → 手动确认目标/类别/功能区 → 手动启动目标抓取预测。
- 两个结果分支始终同时显示；只有实际进入的分支高亮。

```text
目标抓取预测 + 碰撞检查
├─ 有可行目标抓取：仿真展示结果 / 真机人工确认后执行目标抓取
└─ 无可行目标抓取：压覆关系与最终位姿邻接碰撞诊断
   → 针对压覆物体及实际挡住夹爪的邻居规则生成推动参数
   → Push Evaluator 对候选评分排序
   → 仿真展示结果 / 真机人工确认后执行候选 PUSH
```

不再预测、抓取或移除压覆物体；不把 PyBullet PUSH 仿真作为决策阶段。目标抓取碰撞检查和机械臂工作空间、IK、TCP 等实机前置安全校验仍保留。没有压覆或合格邻接阻挡物、没有有效 PUSH 候选或模型评分无效时停止并提示人工处理，不得自动发送动作。真机每次发送动作均须显式确认；PUSH 后需重新采集、分割并确认目标。仿真不回写训练缓存。

## 计算顺序

抓取预测阶段只解码目标抓取候选；PUSH 规则生成在压覆关系及最终位姿邻接碰撞诊断后调用；Push Evaluator 在规则候选确定后调用。界面阶段必须与这一实际计算顺序一致，不得只改变显示文案。

## 压覆关系与候选预览

本流程中的压覆关系指目标上方的遮挡、阻挡关系，不要求物体直接接触目标。判定依据是实际观测点的局部 XY 重叠及局部上下高度；不得增加最大接触间隙要求，也不能用整实例扩张包围盒和整体高度中位数代替局部证据。分离点簇之间没有观测点的区域不算重叠。

同一预测实例若包含多个明显分离且占比显著的 XY 点簇，不能作为一个物理物体建立压覆边，也不能静默挑一个点簇替换下游物体身份。目标属于此类情况时明确提示分割歧义，要求重新分割或选择目标；不能把这一状态说成已确认“没有压覆”。

抓取候选经过碰撞检查全部失败时，仍保留候选预览和切换列表，并标记碰撞未通过。查看候选不会把它设为可执行动作。进入 PUSH 分支后，抓取预览仍可查看，压覆物体的不同颜色高亮持续保留；切换场景或重置任务时清除。

最终抓取位姿的碰撞结果逐候选保留桌面、目标非夹指和具体邻居实例。仅由邻居碰撞阻止、没有同时碰桌面或目标非夹指的候选，提供邻接 PUSH 资格；同一候选碰到多个邻居时，每个邻居均可生成动作，并随动作保留该候选还受哪些邻居阻挡的信息。邻接分支不要求目标与邻居的 XY 投影相交或邻居位于目标上方；压覆分支继续使用局部投影与高度判定。两者使用以下相同的接触点与方向规则。PUSH 评分不因共同阻挡信息自动改写。

## 唯一的 PUSH 候选方向规则（仿真与真机共用）

本节规定对压覆物体及邻接阻挡物生成 PUSH 候选的方向；仿真与真机必须调用同一套候选生成规则。接触点取自待推动物体观测点云中部高度附近的实际外露边界，沿边界约每 `0.01 m` 采样，不在二维凸包的虚构边上插值。只考虑相对于主方向处于被推物体后侧的接触点。固定推动距离 `0.15 m`，方向始终在桌面 XY 平面。

对每个接触点 `p` 分别计算方向。令 `C_t` 为抓取目标中心，`C_o` 为被推物体中心，`m = normalize(C_o.xy - C_t.xy)` 为使被推物体远离目标的主方向，`q = normalize(C_o.xy - p.xy)` 为该接触点指向被推物体中心的方向。仿真和真机应使用同一种基于当前观测实例的中心估计；仿真不得在此规则中使用真机无法获得的真实质心。

计算有符号夹角 `θ = atan2(cross2(m, q), dot(m, q))`，令 `a = |θ|`（以下角度阈值以度计）、`u = clamp((a - 20°) / (70° - 20°), 0, 1)`、`s = u²(3 - 2u)`、`w = 0.15 + (0.75 - 0.15)s`。最终方向为 `d(p) = rotate_xy(m, wθ)`，归一化后令 `d.z = 0`。这是历史数据生成脚本的逐接触点自适应角度补偿：夹角小时主要保持远离目标的方向，夹角大时逐渐朝物体中心偏转；不同接触点可以得到不同方向。默认不额外叠加固定偏角候选（偏角为 `0°`）。不能将同一个 `m` 直接赋给物体上的所有接触点，也不能用局部点云法向的硬阈值取代此方向计算。

如果 `C_t` 与 `C_o` 在 XY 平面重合，主方向未定义；如果 `p` 与 `C_o` 重合，补偿方向未定义。这些退化输入不得静默代入固定 X/Y 轴或另一套候选方向规则，应停止该候选并报告原因，待单独确认退化情形的处理方式。

点云视图以带箭头线段表示候选推动方向，最终选中的动作以红色箭头标识。凸包只作为粗略重叠预筛，不能替代实际接触或真机路径安全校验。
